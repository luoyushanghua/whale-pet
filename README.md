# 鲸鱼娘桌宠

悬浮在 Android 手机桌面上的桌宠。深蓝头发的鲸鱼娘，会呼吸、会走动、
会被你戳、也会嫌你烦。

个人学习作品，**不商用**。

## 功能

- **悬浮窗渲染**：GLSL 单流 alpha 视频（左侧彩色 + 右侧 alpha 蒙版合成为
  1920×720），窗口任意比例都不变形
- **105 段动作**：待机、吃东西、玩耍、时节、小情绪，按权重随机串联，
  一段播完立即接下一段，不留空档
- **情景反应**：插电/拔电、耳机插拔、飞行模式、低电量、久坐提醒
- **情绪系统**：连戳会生气、心情好时会蹦、长时间不理她会犯困
- **通知播报**：QQ/微信来消息时用短句念出来（「谁找你啦」「谁 @你啦」），
  配一条可爱的提示音
- **动作面板**：长按她弹出悬浮面板，按分类挑动作，不进入 App
- **聊天与记忆**：接 API 或本地模型，长期记忆存在本地

## 构建

```bash
# 需要 JDK 21 + Android SDK 35 + Gradle 8.9
gradle assembleDebug
```

⚠️ **仓库不含动作素材**（见 NOTICE）。从源码构建前，需要自行准备
`app/src/main/assets/actions/` 下的 mp4 文件，转码命令见 `HANDOFF.md`。

## 已知问题

- 抛掷（fling）时因为每帧都要移动悬浮窗，帧率约 40fps，略顿
- 横屏旋转后尺寸正常，但部分机型拒绝通过 adb 强制旋转，未做真机验证
